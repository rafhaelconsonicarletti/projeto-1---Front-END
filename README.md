# Sistema Web para ONG

## Sobre o projeto

Este projeto consiste no desenvolvimento de um sistema web para uma Organização Não Governamental (ONG), com o objetivo de apresentar suas atividades, divulgar projetos sociais e disponibilizar uma página de cadastro.

## Funcionalidades

* Página inicial da ONG.
* Página de apresentação dos projetos sociais.
* Página de cadastro.
* Interface desenvolvida com HTML e CSS.
* Recursos interativos implementados com JavaScript.
* Utilização de imagens para complementar a apresentação visual.

## Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript

## Estrutura do projeto

* `index.html`: página inicial.
* `cadastro.html`: página de cadastro.
* `projetos.html`: página de projetos.
* `style.css`: estilos visuais.
* `script.js`: funcionalidades JavaScript.
* `imagens/`: imagens e recursos gráficos utilizados no projeto.

## Como executar

1. Clone ou baixe este repositório.
2. Abra o arquivo `index.html` em um navegador.
3. Navegue pelas páginas utilizando os links disponíveis no sistema.

## Validação

Os arquivos HTML devem ser verificados com o validador oficial do W3C antes da entrega.
